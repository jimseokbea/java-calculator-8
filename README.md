# java-calculator-precourse
## 기능 목록

- [ ] 사용자에게 문자열 입력받기                 ## InputView.java
- [ ] 빈 문자열이나 null은 0으로 처리            ## StringCalculator.java
- [ ] 기본 구분자(쉼표, 콜론)로 숫자 분리하기     ## StringCalculator.java
- [ ] 커스텀 구분자(//) 지원한다                 ## StringCalculator.java
- [ ] 문자열을 숫자로 변환하기                   ## StringCalculator.java
- [ ] 모든 숫자 다 더하기                       ## StringCalculator.java
- [ ] 음수 입력시 예외 처리하기                  ## StringCalculator.java
- [ ] 숫자가 아닌 값 입력시 예외 처리하기         ## StringCalculator.java
- [ ] 결과 출력하기                             ## OutputView.java

## 예외 상황
- 음수가 포함된 경우 → IllegalArgumentException
- 숫자로 변환할 수 없는 경우 → IllegalArgumentException
- 커스텀 구분자 형식이 잘못된 경우 → IllegalArgumentException
